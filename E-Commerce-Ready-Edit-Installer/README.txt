=========================================================
  E-Commerce Ready Edit - Photoshop Panel (Installation Guide)
=========================================================

[বাংলা নির্দেশনা]
১. আপনার ফটোশপ বন্ধ রাখুন।
২. "install.bat" ফাইলে ডাবল-ক্লিক করুন।
৩. ইনস্টলেশন সফল হলে উইন্ডোটি বন্ধ করুন।
৪. এবার ফটোশপ (Photoshop 2022 বা তার নতুন ভার্সন) ওপেন করুন।
৫. উপরের মেনুবার থেকে যান:
   Plugins -> E-Commerce Ready Edit
৬. প্যানেলটি আপনার স্ক্রিনে চলে আসবে এবং আপনি ইচ্ছেমতো বামে বা ডানে ডক করে নিতে পারবেন।

বিস্তারিত ফিচার ও ব্যবহারবিধি জানতে সাথে থাকা "E-Commerce_Ready_Edit_User_Guide_BN.pdf" ফাইলটি দেখুন।

যদি কখনো প্যানেলটি সরাতে বা আনইনস্টল করতে চান:
- "uninstall.bat" ফাইলে ডাবল-ক্লিক করুন।

---------------------------------------------------------
[English Instructions]
1. Close Photoshop if it is open.
2. Double-click "install.bat".
3. Once the installation is finished, close the window.
4. Launch Adobe Photoshop (2022 or newer).
5. From the top menu, go to:
   Plugins -> E-Commerce Ready Edit
6. The panel is ready to use!

To uninstall:
- Double-click "uninstall.bat".
